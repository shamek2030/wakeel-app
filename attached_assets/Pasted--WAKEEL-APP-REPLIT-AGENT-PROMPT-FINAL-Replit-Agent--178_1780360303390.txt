## SECTION 3 — SQLite DATABASE (LOCAL ONLY)

### database.js — create all tables on first launch

```sql
/* students table */
CREATE TABLE IF NOT EXISTS students (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  national_id TEXT UNIQUE,
  name TEXT NOT NULL,
  grade TEXT,
  section TEXT,
  guardian_name TEXT,
  guardian_phone TEXT,
  created_at TEXT DEFAULT (datetime('now'))
);

/* records table — all 15 official registers */
CREATE TABLE IF NOT EXISTS records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  form_code TEXT NOT NULL,       -- e.g. 'و.ط.ع.ن-04-03'
  form_number INTEGER,           -- 1..15
  title TEXT NOT NULL,
  student_id INTEGER,
  body_json TEXT,                -- JSON string of form fields
  ai_body TEXT,                  -- AI-generated Arabic text
  status TEXT DEFAULT 'draft',   -- draft | approved | archived
  created_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (student_id) REFERENCES students(id)
);

/* violations table */
CREATE TABLE IF NOT EXISTS violations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id INTEGER NOT NULL,
  degree INTEGER NOT NULL,       -- 1..4
  description TEXT,
  deduct_type TEXT,              -- conduct | attendance
  deduct_points INTEGER,
  procedure_text TEXT,
  created_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (student_id) REFERENCES students(id)
);

/* evidence table — شواهد */
CREATE TABLE IF NOT EXISTS evidence (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  category TEXT,                 -- achievement | training | administrative
  file_uri TEXT,
  description TEXT,
  created_at TEXT DEFAULT (datetime('now'))
);

/* settings table — single row */
CREATE TABLE IF NOT EXISTS settings (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  school_name TEXT DEFAULT '........',
  education_admin TEXT DEFAULT 'الإدارة العامة للتعليم بمكة المكرمة',
  vice_principal TEXT DEFAULT '',
  principal TEXT DEFAULT '',
  admin_assistant TEXT DEFAULT '',
  logo_uri TEXT,
  school_level TEXT DEFAULT 'متوسطة',
  is_pro INTEGER DEFAULT 0,
  pro_expiry TEXT
);

/* Insert default settings row */
INSERT OR IGNORE INTO settings (id) VALUES (1);
```

### queries.js — export these functions:

- `getSettings()` → returns single settings row
- `updateSettings(fields)` → partial update
- `importStudents(rows[])` → bulk insert from Excel
- `getStudents(searchQuery?)` → with optional search
- `getStudent(id)` → with all related records + violations
- `insertRecord(data)` → save form record
- `getRecords(formNumber?)` → filter by form type
- `updateRecord(id, fields)` → approve / archive
- `insertViolation(data)`
- `getStudentViolations(studentId)`
- `insertEvidence(data)`
- `getAllEvidence()`

### Form31Screen.jsx — نموذج (31) تحويل طالب — FULL IMPLEMENTATION

7-step workflow. Each step is its own JSX block within this file.

**Step 1 — بيانات التحويل (الوكيل يُدخلها نيابةً عن المعلم)**

- Student selector: search field → picks from SQLite students
- Teacher name: text input
- Subject: text input
- Period: number picker (1..8)
- Reason checkboxes (exactly as in ministry form):
  □ عدم أداء الواجب
  □ مشاغبة
  □ تأخر عن الحصة
  □ ضعف دراسي
  □ أخرى (with free text)
- Problem clarification: multiline text (optional — AI completes it)
- Primary button: “إرسال للذكاء لصياغة النموذج رسمياً”

**Step 2 — AI Processing**

- Spinner + “الذكاء يصيغ النص الرسمي…”
- Calls Claude API with prompt:
  “أكتب إيضاح مشكلة رسمية للنموذج 31 (تحويل طالب لوكيل شؤون الطلاب) بصياغة وزارة التعليم السعودية. الطالب: {name}، الصف: {grade}، المادة: {subject}، الأسباب: {reasons}. اكتب فقرة واحدة رسمية مختصرة لا تتجاوز ٤ أسطر.”
- Saves result to SQLite records table (status: draft)

**Step 3 — النموذج مُعَدّ بالذكاء**

- Shows full MoEHeader
- Shows: student info row / subject + period / date
- Shows reasons (colored badge)
- Shows AI-written clarification (accentBg, editable)
- Teacher name + signature line

**Step 4 — إجراء الوكيل**

- Editable textarea for vice principal action
- Deduct type selector: السلوك | المواظبة
- Deduct points (auto-calculated by degree: 5/10/15/20)
- Primary button: “اعتماد وإحالة للموجه الطلابي”
- Saves to SQLite

**Step 5 — متابعة الموجه الطلابي**

- Step tracker: 1✓ 2✓ 3● 4○
- Counselor response textarea
- Recommendation: تثبيت الحسم | إلغاء الحسم
- “إرسال لمسجّل المعلومات” button

**Step 6 — مسجّل المعلومات — الحسم**

- Step tracker: 1✓ 2✓ 3✓ 4●
- Summary card: student / deduct type / points
- “تأكيد الحسم وأرشفة النموذج” (green button)
- Saves final status to SQLite

**Step 7 — مكتمل ومؤرشف**

- Success animation (green checkmark circle)
- “اكتملت دورة النموذج — دوّر عبر ٤ أطراف”
- Timeline of 4 parties + actions
- Export PDF (Pro) | رفع كشاهد (Pro)

## SECTION 9 — AI HOOK (Pro only)

### useAI.js

```js
export function useAI() {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  async function generate(prompt, systemPrompt) {
    setLoading(true);
    setError(null);
    try {
      const response = await fetch('https://api.anthropic.com/v1/messages', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          model: 'claude-sonnet-4-20250514',
          max_tokens: 1000,
          system: systemPrompt || 'أنت مساعد وكيل شؤون الطلاب في مدرسة سعودية. تكتب بالعربية الفصحى بأسلوب وزارة التعليم السعودية. كن موجزاً ورسمياً.',
          messages: [{ role: 'user', content: prompt }],
        }),
      });
      const data = await response.json();
      return data.content?.[0]?.text || '';
    } catch (err) {
      setError(err.message);
      return '';
    } finally {
      setLoading(false);
    }
  }

  return { generate, loading, error };
}
```

## SECTION 13 — DYNAMIC FORM RENDERER INSTRUCTION

In `RecordDetailScreen.jsx`, build a `DynamicFormRenderer` component:

```jsx
function DynamicFormRenderer({ formNumber, bodyJson, onChange }) {
  // 1. Import FORM_SCHEMAS object that maps formNumber → field specs
  // 2. For each field in schema, render the appropriate input:
  //    - text/phone/number → TextInput
  //    - textarea → TextInput multiline with rows
  //    - date → DatePicker or text input with HH/MM/YYYY hint
  //    - select → Modal picker or segmented buttons
  //    - checkbox → TouchableOpacity with check icon
  //    - signature → placeholder TouchableOpacity "اضغط للتوقيع"
  // 3. For table-type forms (3,4,5,6,7,8,14): render AddRow button + FlatList of rows
  // 4. For section-type forms (13): render collapsible section cards
  // 5. All labels RTL, all inputs RTL
  // 6. Values saved to bodyJson (JSON string) in SQLite
}
```

Export `FORM_SCHEMAS` as a constant object in `src/db/formSchemas.js`:

```js
export const FORM_SCHEMAS = {
  1:  { type: 'sections', sections: [...] },
  2:  { type: 'flat',     fields: [...] },
  3:  { type: 'table',    header_fields: [...], row_fields: [...], footer_fields: [...] },
  // ... all 15
  11: { type: 'workflow', handled_by: 'Form31Screen' },
};
```
